# 桌面小仙 · 产品路线图

> 定位：一只住在你 Windows 桌面上的修仙小伙伴——是桌宠，是游戏主角，也是你未来的桌面效率伙伴与 AI Agent。

## 已交付（v0.1）

- 桌宠壳：透明置顶小窗、自由拖动、位置锁定、位置持久化、系统托盘（显示/隐藏、开机自启）
- 养成：喂食（灵米/灵果）、洗澡（净身术）、吐纳、闭关、炼丹、炼器、20 级境界、天劫护法小游戏
- 战斗：点击桌宠进入 2.5D 俯视 ARPG——无缝开放秘境（青竹林/毒沼/剑冢/石岭/炎窟五区域、仇恨脱战、区域刷新、B 键回城、小地图、Boss 赤炎蛟必掉法宝）
- 美术：全部 AI 生成实装（立绘×3、妖兽×5、地表×4、装饰×4、渡劫背景）

## 本迭代（v0.2）

- QQ 宠物式交互：窗口完全透明，平时只见小仙本体；鼠标悬浮才浮现功能环，点击播放对应动画
- 形象选择：男/女小仙立绘切换（状态持久化）
- 开放世界区域奇遇：采药点、遗迹宝箱、剑冢顿悟台

## 已交付（v0.3，2026-10-05）

- **音乐舞蹈（节拍驱动）**：GSMTC 真实播放状态检测（暂停不再误舞）；舞步节拍由 BPM 驱动——设置页滑块 + 跟着音乐点拍（Tap Tempo）标定，按曲目记忆（GSMTC 提供曲名，不提供音频波形，故不做自动测拍，诚实标注）
- **专注统计**：近七日闭关柱状图（当日朱砂高亮）、周汇总、连续闭关天数；按日账本只留 14 天防存档膨胀
- **换装配色**：七套配色方案（青玉/丹朱/鎏金/月华/墨染/赤焰），Canvas filter + 叠色整体染色，灵光同步换色；分层换装（发型/服饰）需资源包分层素材，契约见 `src/game/looks.ts`
- **战绩分享卡**（插队交付）：秘境结算生成 1080×1440 战报图，可保存/复制
- **独立设置页**（插队交付）：音律/观感/洞府三组，左侧可拖拽模拟桌宠窗实时预览

## 近期（v0.4）

- **捏脸/换装·分层版**：发型、脸型、服饰自由组合；立绘分层渲染（依赖分层素材包，契约已定义）

## 中期（v0.5–v0.7）

- **TodoList**：桌面待办，完成任务=小仙获得修为奖励，游戏化驱动
- **思维导图**：洞府内「悟道图」，节点式整理思路，可关联待办
- **专注模式**：Windows 全局专注——白名单之外的软件/网站一律拦截或隐藏，小仙全程护法，破功则「心魔入侵」
- **效率面板**：参考 Quicker / uTools，全局热键唤出快捷面板（搜索、剪贴板、常用操作、自定义动作）

## 远期（v0.8+）

- **聊天大模型接入**：小仙开口说话，可对话、可提醒、可答疑
- **完整桌面 Agent**：小仙不止陪聊——能帮你操作电脑、查资料、跑任务，成为住在桌面上的完整 AI 伙伴
